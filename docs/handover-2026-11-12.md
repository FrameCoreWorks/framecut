# Handover 2026-11-12: FrameCut 0.1.0

## What happened

The owner said "startujemy" on 2026-11-12 for FrameCut as its own plugin. This repository was created the same day (public, `main` only) and holds FrameCut 0.1.0, a complete standalone video editing plugin that Creative Studio uses as its editing companion.

Decisions by the owner (2026-11-12): repository `FrameCoreWorks/framecut`; the editing skill and the whole captions skill belong to FrameCut; Creative Studio keeps links to FrameCut and orchestrates it, with the installation route in its first setup; FrameCut works standalone and offers the plugins that extend it once at first setup, installing only what the user picks; descriptions present FrameCut as a standalone plugin; Apache-2.0; one skill; no light version for ChatGPT Work.

## Source comparison

`python3 tools/compare_studio.py <studio checkout>` compares FrameCut with the editing and caption files of a Creative Studio checkout. Against Creative Studio 1.178.1 (main `bc3724ea`), the last release that carries them: 54 files, 34 identical, 19 adapted (paths, the skill's top section and links to Studio-only files written as "Creative Studio: `path`"), 1 replaced (the captions skill's `agents/openai.yaml`, now covered by FrameCut's own), 0 missing.
