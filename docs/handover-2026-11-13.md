# Handover 2026-11-13: FrameCut 0.1.1

## What happened

The owner approved a repair release of Creative Studio, FrameMotion and FrameCut after the dependency review of 2026-11-13. FrameCut's part is small: installation through its own marketplace only, music rules for reels and a corrected credit.

## Changes in 0.1.1

- `references/companion-plugins.md`: music for reels and social films comes from code first (platforms mute or claim library music even under CC BY), the user is warned before someone else's track, about -14 LUFS with the peak below -1 dB; the Creative Studio install route names the marketplaces to add first.
- `INSTALL.md`: `framecut` is FrameCut's only marketplace. Creative Studio 1.180.0 no longer lists FrameCut in its own marketplace and depends on `framecut@framecut`; an older `framecut@framecore-works` copy is replaced by hand (checked in an isolated Claude Code configuration on 2026-11-13).
- `references/readability-defaults.md`: the readable hold rule is credited to FrameMotion's motion craft.
- `tools/check.py` prints the end of a failing test's output.

## Verification

`python3 tools/check.py` passes on the Mac with FFmpeg built with libass (Homebrew's FFmpeg has no libass: eight caption and render tests then stop on `missing_capability`). ChatGPT Work, Codex and the Claude apps: NOT_RUN in this release.
